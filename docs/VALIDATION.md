## 反馈与结论的边界

用户反馈：固定尺寸已经等于最大化后的尺寸，但再次点击最大化或拖到顶部仍不能正确铺满屏幕。本机的旧版基线和新版候选都通过了经典记事本的最大化及顶部吸附，未能稳定复现反馈中的旧版异常，因此没有证据认定唯一根因或声称所有显示环境的问题都已解决。

v1.2.1 针对状态与位置问题加强处理：连续稳定 300 ms 后捕获或纠正，移动/缩放结束等待 400 ms；捕获最大化尺寸前核对可见工作区覆盖；保留记录的屏幕尺寸模式并识别目标 DPI 下的隐形边框；已最大化却没有覆盖工作区时执行有次数和超时限制的还原、重新最大化。顶部另有兜底请求。本机正常最大化与原生 Windows 顶部吸附通过；异常位置修复和顶部兜底没有通过人为故障注入触发，属于已审查但未实测触发的防御分支。

## 尺寸与资源说明

外部矩形包含 Windows 隐形调整边框，所以最大化外部尺寸可能大于屏幕工作区。判定铺满需要同时考虑最大化状态、位置和 DWM 可见边界，而不仅是两个宽高数字。

v1.2.1 文件为 170.5 KiB，使用原生控件、GDI、WinEvent 事件、1 秒兜底检查与 80 ms 待稳定检查，没有外部运行时。v1.2.1 未重新进行托盘静止时的资源采样；3.00 MiB 专用内存、19.73 MiB 工作集、约 1.17% 单逻辑处理器 CPU 时间比例属于 v1.2.0 的历史 20 秒样本，详见旧版记录，不是新版测量值。
