# v1.1.0 验证记录

验证对象：本项目源码使用 MSVC 14.44 编译得到的 x64 程序，版本 1.1.0，大小 164,864 字节。最终便携包使用同一编译文件。

环境：Windows 11 IoT Enterprise LTSC x64，系统版本 10.0.26100，当前显示缩放 100%。目标为系统经典记事本的空白窗口。本记录只写功能证据，不发布原始截图、窗口列表、个人文件内容或原始诊断日志。

## 本版交互回归

| 操作 | 实测结果 |
| --- | --- |
| 初始面板 | 卡片、状态徽标、尺寸、按钮、列表、说明完整显示，无重叠；固定与解除按钮初始禁用 |
| 单击列表目标 | 行显示选中反馈，固定按钮启用 |
| 双击列表目标 | 自动记录外部尺寸 1023 × 790，固定/当前两栏一致，绿色“固定中”徽标 |
| 缩小目标 | 目标变为 859 × 667，自动恢复至 1023 × 790；该次日志时间差约 62 ms |
| 最小化 | 保留固定尺寸，当前栏显示“已最小化”，徽标变为黄色“已暂停” |
| 还原 | 继续固定，目标恢复至记录尺寸 |
| 最大化 | 自动还原至 1023 × 790，该次观测时间差约 78 ms |
| Ctrl + Alt + U | 解除，目标和尺寸显示复位，徽标恢复“未固定” |
| 拖动主按钮 | 面板降低层级露出目标，松开后正确选中记事本并固定；面板重新显示 |
| 收起到托盘 | 面板从可见窗口列表消失，进程与固定保持运行 |
| 再次运行 EXE | 唤回现有面板，进程数仍为 1，固定记录仍在 |
| 关闭目标 | 自动解除，显示目标关闭说明 |
| 刷新列表 | 已关闭的目标消失，固定按钮恢复禁用 |
| 退出 | 面板与进程退出 |

恢复时间为上述具体操作的日志观测值，不是通用性能保证。未承诺拖动期间完全禁止瞬时变化。

## 已有引擎验证与边界

1.0.0 的同一尺寸恢复引擎已验证扩大/缩小恢复、允许移动、快捷键固定前台窗口、最小化暂停、最大化还原、解除、目标关闭、托盘与退出。本版保留引擎并完成上述 UI 回归。

Windows 10、不同 DPI 的跨显示器移动、管理员权限目标、独占全屏及受保护窗口尚未在本机逐项验证。项目按 Win10/11 API 兼容方式构建；Windows 10 支持仍待真机测试。
